# Domínio Store — Front-end (Vercel)

Arquivos estáticos em HTML5, CSS3 e JavaScript Vanilla.

## Deploy na Vercel

1. Suba esta pasta `frontend/` como um repositório na Vercel.
2. Framework preset: **Other** (sem build). Output directory: raiz.
3. A API consumida está em `scripts-js/config.js` (`API_URL`).

## Páginas

- `index.html` — vitrine, busca, filtros, carrinho e meus pedidos
- `login.html` — autenticação
- `cadastro.html` — criação de conta (sempre perfil cliente)
- `dashboard.html` — painel de Admin/Vendedor (KPIs, gráfico donut, planilha de preços/estoque, pedidos)
