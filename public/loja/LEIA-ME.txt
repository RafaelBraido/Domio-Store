DOMÍNIO STORE — front-end (pasta "loja")
========================================
Copie ESTA pasta inteira para o seu projeto e abra "index.html".
Todos os caminhos são relativos: nao renomeie as subpastas css/, js/ e img/.

Arquivos e o que cada um faz
----------------------------
index.html    -> vitrine, carrinho e checkout Pix (3 passos)
login.html    -> entrar (admin de demonstracao: rafaelbraido126@gmail.com / admin123)
cadastro.html -> criar conta (o 1o usuario criado vira admin)
perfil.html   -> editar dados, senha e foto do usuario
admin.html    -> painel: KPIs, produtos, pedidos em andamento, historico, usuarios

css/estilo.css   -> UNICA folha de estilo do site
js/config.js     -> configuracoes (API_URL, USAR_API_LOCAL, WhatsApp, chave Pix)
js/api-local.js  -> banco de dados no navegador (modo demonstracao)
js/services.js   -> chamadas da API (ServicoAuth, ServicoProdutos, ServicoPedidos...)
js/vitrine.js    -> logica da vitrine, carrinho, checkout e "meus pedidos"
js/auth.js       -> login e cadastro
js/perfil.js     -> minha conta
js/admin.js      -> painel do administrador
img/pix.jpg      -> QR Code Pix mostrado no passo 2 do checkout

Sistema 100% estatico
---------------------
Nao existe back-end: os dados (usuarios, produtos e pedidos) ficam
salvos no localStorage do navegador, pelo arquivo js/api-local.js.
Basta abrir index.html no navegador.

Fluxo de compra
---------------
1) Adicionar ao carrinho (nunca acima do estoque)
2) FINALIZAR COMPRA -> escolher a CIDADE
3) FALAR COM O VENDEDOR NO WHATSAPP (+55 42 98422-4752) para NEGOCIAR
   (so depois de negociar o botao de pagamento libera)
4) IR PARA O PAGAMENTO -> escanear o QR Code Pix
5) JA FIZ O PAGAMENTO -> pedido criado como PENDENTE e estoque reservado
6) O admin confirma no painel: PENDENTE -> PAGO -> FINALIZADO
